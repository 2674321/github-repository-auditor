# Identidad visual — GitHub Repository Auditor

Este directorio contiene recursos visuales livianos para README, documentación e interfaz.

- `app-icon.svg`: icono cuadrado minimalista, apto para tarjetas, accesos directos y portfolio.
- `hero-banner.svg`: cabecera 3:1 para README, landing, dashboard o pantalla de inicio.

## Uso en interfaz

```html
<img src="docs/branding/hero-banner.svg" alt="GitHub Repository Auditor" class="brand-hero">
```

```css
.brand-hero { width: 100%; height: auto; border-radius: 18px; display: block; }
```

Los recursos no contienen datos operativos ni personales y pueden reutilizarse sin afectar la lógica del sistema.
